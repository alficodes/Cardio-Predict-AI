CardioPredict AI is an end-to-end Machine Learning web application and clinical decision support system designed to predict coronary heart disease risk from patient clinical biomarkers. The project was developed as the Week 4 Final AI Capstone for the AI Pioneers Internship program on Yuva Intern.

The system utilizes the gold-standard UCI Cleveland Heart Disease dataset comprising 303 patient records across 13 physiological parameters including resting blood pressure, serum cholesterol, chest pain type, ST depression, fluoroscopy vessel occlusion, and thallium stress test results. The data engineering pipeline handles missing values, removes duplicates, and applies Scikit-Learn’s StandardScaler fitted strictly on the training partition to prevent data leakage during an 80/20 stratified train/test split.

To determine the optimal predictive architecture, five classification models were trained and benchmarked under 5-Fold Stratified Cross-Validation: Logistic Regression, Random Forest, Support Vector Machine (SVC), Gradient Boosting, and K-Nearest Neighbors (KNN). An extensive hyperparameter search via GridSearchCV optimized the Random Forest Classifier, prioritizing clinical recall (sensitivity) to minimize missed cardiac diagnoses. On the holdout test set, the final model achieved an outstanding 93.94% Recall (Sensitivity), 90.80% ROC-AUC score, 84.93% F1-Score, and 81.97% overall accuracy.

Model persistence and serialization were implemented using both Joblib and Python’s native Pickle library, accompanied by structured JSON metadata capturing hyperparameters, training timestamps, and performance metrics. The model is served through a lightweight, production-grade Flask web application featuring a dual interface: a responsive, accessible patient/clinician web dashboard with single-click sample loading and printable diagnostic reports, and a stateless RESTful JSON API (/api/predict) for third-party electronic health record (EHR) integration. The solution includes an automated test suite with 11 unit and integration test cases covering data processing, model inference parity, probability calibration, and API error handling. Complete technical documentation has been compiled in a formal Word document report (.docx) alongside an executive PowerPoint presentation (.pptx).
